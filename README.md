# Calculator

On-screen calculator built with HTML, CSS and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

Supports basic arithmetic operations (+, -, *, /) with chained calculations and division by zero error handling.

## Features

- Basic operations: add, subtract, multiply, divide
- Chained calculations (e.g. 5 + 3 - 2 = 6)
- Clear button to reset
- Division by zero error handling
- Dynamic display
